使用真实场景、完整应用程序和共享待办事项，探索 GitHub Copilot 在整个软件开发生命周期中的应用。你将通过迭代来规划更改、编写代码、测试行为、审查拉取请求，并使用智能体管理工作。

## 场景

你是 Tailspin Toys 的新开发者。这是一家虚构公司，为棋盘游戏提供众筹服务，整体采用开发者主题。团队的待办事项已整理为 GitHub 问题，随时可供你处理，其中既包括筛选和分页等功能任务，也包括无障碍访问和编码标准等质量改进。

## 选择环境

无论你在哪里工作，都可以使用 GitHub Copilot。选择适合你构建方式的环境。每个工作坊都有独立的设置流程，并使用共享的 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

在终端中使用代理式助手。体验 Plan 和 Autopilot 模式、说明、技能、自定义智能体、Playwright MCP、Agent Merge 和实用斜杠命令。

### [GitHub Copilot app][app]

在桌面应用中运行并行智能体会话、切换会话模式、协作使用画布，以及管理 GitHub 问题和拉取请求。

### [GitHub Copilot cloud agent][cloud]

将 GitHub 问题分配给异步智能体，引导其工作、监控进度，并审查它创建的拉取请求。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot。直接在编辑器中体验 Copilot Chat 智能体模式、MCP 服务器和自定义智能体。
